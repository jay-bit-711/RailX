# RailX

Sequential journey OS for Indian Railways travellers — plan, ride, help, remember.

**Live:** https://railx-48e91.web.app  
**Handoff (read this first):** [docs/HANDOFF.md](docs/HANDOFF.md)

## Quick start

```bash
npm install
npm run dev
npm run build
firebase deploy --only hosting
```

## Stack

Vite · React · Tailwind · Firebase (Auth, Firestore, Hosting)
